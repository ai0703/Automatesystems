## 3. Core Problem (The Villain)

Revenue is lost in boring operations work:

- Leads arrive across **too many sources**
- Enrichment + scoring are **manual/inconsistent**
- CRM gets **messy** (duplicates, missing fields, wrong lifecycle stages)
- Routing is **slow** (no SLA enforcement)
- Follow-up **breaks** (tasks not created, sequences not triggered)
- Timing signals are **missed** (job changes, new hires, intent)

**Business cost:** Slower speed-to-lead, lower conversion rate, missed windows, wasted rep time, lower pipeline created.

## 10. Technical Capabilities (Behind the Scenes)

### Stack & Tools
- **Primary automation platform:** n8n (workflows, retries, error handling, logging)
- **Custom code deployment:** DigitalOcean
- **Languages:** Python (primary), JavaScript, HTML/CSS
- **CRM integrations:** HubSpot, Salesforce, Zoho

### Lead Sources / Enrichment
- **General leads:** AiArc (database, $299/250k credits plan)
- **Local leads:** Google Maps scraping system + domain extraction + email scraping
- **Signal-based leads:** Clay (when the data signal requires it)
- **Approach:** Need-based sourcing — use the most cost-effective pipeline for the job

### Email Infrastructure
- **Google Workspace:** Domain-reputation driven. 2–3 weeks warmup → start at 5/day → ramp to ~30/day per inbox
- **Microsoft (Azure/M365):** Tenant-behavior driven. 1 domain/tenant, up to ~100 accounts, ~5/day per inbox
- **Mix:** 70% Microsoft / 30% Google across multiple providers
- **Philosophy:** Scale by adding inboxes, not pushing higher volume. Optimize for consistency and longevity over spikes.

### Outreach Platform
- **PlusVibe** for campaign management (sequences, lead uploads, subsequences)
- Multi-step email sequences with spintax variation
- Automated subsequences triggered by lead status (e.g., INTERESTED → new sequence)
